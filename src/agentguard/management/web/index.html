Private-runner pilot

Python, AgentGuard HTTP protokolü veya uyumlu container. Otomatik framework keşfi ve sıfır yapılandırma yoktur. Test sonucu genel güvenlik sertifikası değildir.

1 · Agent’ını Bağla

Agent kodunu sunucuya yüklemeyin. Kendi makinenizde/CI’da private runner ve proje workspace’i hazırlayın; kaynak hash’ini CLI ile hesaplayın. HTTP için bağımsız namespace/reset/snapshot/cleanup observer gerekir. Kaydetmek erişim doğrulaması değildir.

Enrollment 10 dakika geçerli; API anahtarı değildir. Güvenli terminal girdisiyle runner enroll komutuna verin. Bu sayfada yalnız bir kez görünür; çıkışta temizlenir.



2 · Test Et

Yalnız seçilen frozen suite test edilir; bütün risklerin kapsandığı iddia edilmez.

3 · Rapor Al
Customer private runner kanıtı; bağımsız platform attestation’ı değildir. Execution, policy, cleanup ve kapsamı ayrı inceleyin. Belirsiz/eksik kanıt BLOCK olur.


Sürümleri karşılaştır (manuel private evidence upload)
Runner cache’indeki iki canonical JSON’u seçin; indirilen redacted sunum artifact’i comparison authority değildir. Aynı oracle/suite ve projeye ait run’lar gerekir.
